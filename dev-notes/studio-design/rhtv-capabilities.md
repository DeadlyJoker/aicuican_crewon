# rhTV 插件能力盘点

本参考记录 2026-11-09 对用户指定发行包的静态检查，以及用户授权后的只读在线目录检查，用于 CrewON Studio 产品范围设计。本机安装及账号检查另见[安装核验](rhtv-installation.md)；以下能力声明不等于已完成真实生成，实际执行仍取决于当前服务端、账号权限、余额和功能开关。

## 包与证据

下载地址为 [rhtv-canvas-clients-0.7.1-build-11.zip](https://rh-canvas-files-1252422369.cos.ap-beijing.myqcloud.com/rhtv-clients/rhtv-canvas-clients-0.7.1-build-11.zip)。外层 README 写的是“0.7.1 · build 15”，与 URL 文件名中的 build 11 不同，不能只按文件名标识具体内容。三个组件 manifest 的版本均为 0.7.1，releaseId 分别为 CLI `a61f71262e76357afc9a`、MCP `257f9e31030048448eba`、Codex Plugin `fce1cc5489fc2d84f4d0`。

组件的 `USAGE.md`、`payload/skills/canvas/SKILL.md`、`payload/scripts/mcp-tools.mjs`、`alignment-tools.mjs` 和 `alignment-schema.mjs` 是本次能力证据。三个组件的上述工具定义和主要 CLI/MCP 脚本内容哈希相同，业务能力共用，区别在安装入口和宿主接入方式。静态声明合计 68 个 MCP 工具：原有 19 个与资源式接口 49 个；本轮已在安装后的本机 stdio MCP 中完成 initialize 和 tools/list，实际注册 68 个工具；远程业务仍需账号授权后分别检查。

发行包可读不代表允许复制或再分发。解压内容中未发现 LICENSE 或 NOTICE；本次只记录公开接口与产品行为，不据此把其实现引入 CrewON。

## 网页有入口，插件没有完整开放的能力

插件手册明确拒绝 `video-clip`，不提供时间线、剪辑和导出编辑。网页中的剪辑入口不能当作这套 MCP 已具备的能力。Studio 如需完整出片，必须单独设计并实现镜头时间线、裁切、声音混合、字幕、预览和编码交付。

已观察到的网页还有 3D 导演台、片场预演、深度捕捉、画板、角色与服装、声音配置、工作流、社区、模板、MCP 与插件入口。当前客户端未暴露这些模块的完整专用接口；通用节点和模型参数只能支持其中一部分，不能凭接口名称认定它们已端到端可用。参考视频的结构解析、一键复刻、互动影游，也不能从该包确认完整机制。

包里的 Codex 插件是一个 Skill 加共享 CLI 和本地 stdio MCP 的组合，没有完整的独立前端，也不是可离线运行的媒体执行引擎。其业务请求仍调用选定 RunningHub Canvas API。安装它有助于理解和检查参考产品，但不能替代 CrewON 自己的 DSH 插件与可替换媒体 API 设计。

## Studio 产品范围建议

Studio 以“作品项目 + 无限画布 + 资产与版本 + Agent 创作编排”为共同基础。首页用一个目标输入和已有内容导入开始，制作方案按目标推荐；图片、视频和声音是项目内的内容与工具。参考产品的四种模式用于了解工作方式，不直接决定 Studio 的一级导航。

短剧是端到端作品模板，覆盖剧本、角色与场景、分镜、声音、剪辑和交付。图片与视频创作可以从单个节点完成，也能被短剧复用。专业扩展包括角色造型、镜头预演与 3D 导演台、画板、参考解析、可复用制作工作流；社区和分享另列内容分发范围，不与本地制作恢复混在一起。

DSH 提供专家、工具、会话、审批、原生执行与轨迹；Studio 持有创作项目、画布、资产采用版本、剪辑和交付记录；媒体 API 仅执行明确请求。原始任务 ID、结果采用、修改影响范围与费用确认应纳入共同设计，不能等生成接好后再补。产品视觉和 DSH 插件开发 SOP 的审查见同目录独立审查记录。

## 本轮候选设计的参考限度

2026-11-09 的只读查询中，`canvas_node_list` 对用户所给画布的图片和全部节点返回 BEST_EFFORT 视图 0 项，但 `canvas_list` 的画布摘要标出 33 节点，旧 `canvas_query` 以有界 10 项查询成功读取到 `rh-script-agent` 与 `rh-entity`。新旧查询结果不一致，不能说画布为空，也不能据新接口的 0 项推断候选或采用语义。Studio 的固定候选、输入与采用分离、显式比较采用和本地操作记录，依据本产品的低成本修改与保留成果目标设计并在本地原型验证，不作为参考平台已实现相同行为的证据。

后续只读 `canvas_query` 使用 `nodeLimit:40`、`edgeLimit:40`，该次完整返回 33 节点和 34 连线，`hasMore=false`、`truncated=false`、`selectionComplete=true`，仍带 `BEST_EFFORT_VIEW`。所读实体的 `params` 只见 `prompt`、`quality`、`resolution`，连线字段为 `id`、`source`、`target`、`sourceHandle`、`targetHandle`、`endpointOutsidePage`，未给出明确的资产版本字段；这仅说明该接口快照未提供这些信息，不能证明网站不支持版本引用。

## 剧本工作台与查询限度

本轮实际只读打开参考站“剧本工作台”，看到剧本、资产和分镜标签，其中分镜当前禁用；剧本内有故事设定、分集大纲和正文，左侧列出五集目录，当前所见正文只读。界面提供下载全部、下载当前集和解析资产入口，资产页按角色、场景、道具组织。未点击解析、生成或编辑参考站内容，未复制其故事文本。

`canvas_script_content_get` 对所查内容返回 `UNSUPPORTED_SCHEMA`。这说明本次接口未能读取该剧本文档，不能把工具已注册或网页正文可见写成剧本 API 已全部适配。可借鉴分场组织和正文／资产的关系，Studio 的草稿、审阅选中输入、保留旧输出与动态分场仍按本产品目标设计；实际接口接入和执行语义需要单独验证。
