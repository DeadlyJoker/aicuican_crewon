# 视频模型研究快照

此目录只服务本地交互 Demo，不连接 rhTV 生成、不代表 CrewON 已配置这些服务或拥有对应模型授权。运行时读取本地快照；正式接入仍须使用独立供应商 API、项目凭据和 DSH 插件生命周期。模型名称不是跨供应商参数协议。

## 来源

2026-11-10 在自建研究画布逐个点击 Seedance、Kling、MiniMax、HappyHorse、Wan、Vidu、全能视频 X／V／Om、Midjourney、LTX、PixVerse，共记录 41 个模型项及其制作方式。源站组合筛选按任一能力匹配；例如同时选首帧和视频编辑时，Kling 4.0 仍出现。品牌切换本身不选择模型。菜单主栏约 320px，右侧模型浮层跟随品牌行，每项名称及能力分层展示。

通过已安装 rhTV CLI 只读读取当前账号可见目录（154 个按制作方式拆分的定义），以及具体定义的 `schema.properties`、基础／高级字段标题、显示状态和参数依赖；Demo 中 41 个模型项映射到其中 111 个具体定义。`reference-video-catalog.js` 保存此快照，不保存账号、授权令牌、请求回执、SKU 或充值价格。原站当前用户可见结果不能外推为所有账号的实时目录。

## 映射与参数

模型项按原站显示名称分组，每个制作方式保留独立 `modelCode`；没有把 `ratio` 和 `aspectRatio`、`duration` 与界面旧 `seconds` 当作同一通用 API 字段。选定具体模型后，参数使用该定义的原始字段名、类型、默认值及枚举；只读素材字段由现有参考选择器管理，不展示为可编辑 JSON。切换模型或方式重新初始化该定义的默认参数，不携带另一个模型的字段；提示词和锁定参考保留。首尾帧不受新模型支持而首帧受支持时转为首帧，额外参考保留为未生效。

Kling O3 的默认 Std、Hailuo 2.3 的默认 Standard，以及 Minimax H3 RH Enhanced 的默认非 app 变体，已经在研究画布选择并用只读节点查询交叉核对。随后恢复原 Seedance 2.5 Global／首尾帧、5 秒、720p、空提示词；视频节点位置及两条入边与初始查询一致，未提交生成、费用或取消。其余显示名与目录精确对应；Kling V3.0、Hailuo 02 等显示别名在生成快照时明确映射，匹配多项或缺少定义会拒绝生成目录文件。底层 Pro、4K、Turbo 等额外变体的联动选择仍未完整复刻，不宣称已经覆盖其全部版本切换。

基础与高级设置按照原始配置的 `advanced` 和 `display` 区分，字段标题来自该配置。数值范围与步长取自定义，未规定步长的浮点值不额外限制为 0.1。样片模式按该模型的 `draftParamValueTrue` 将分辨率切换为 480p。没有声明输出时长的模型不凭目标节点旧时长虚构输出时长。此处仅记录示例参数，不调用媒体服务，不做素材转换或真实渲染。

## 数据兼容与验证

旧项目的 project／preview／quality 配置继续存在，不自动选择具体模型，也不修改旧候选；显式选择具体模型才写入新的模型项和参数草稿。新候选保存准确模型标识、显示名称及参数副本，后续修改不会改写旧记录。原有深度编辑入口复用相同设置，不显示与所选模型相矛盾的旧时长表单。已保存但不在快照中的模型项显示错误并禁止制作，不静默切换另一模型。

本地 Web 实测 Seedance 首尾帧切 Hailuo 首帧、参数重置、刷新、基础／高级参数、样片模式规则、旧候选和深度编辑入口；视频编辑模式实选现有视频采用版本，仅该视频用于候选，图片保留但不参与。390px 模型目录和声音类型菜单已截图，底部控件单独布局，缩窄后选中节点避让左侧工具栏。未完成全部 111 个定义的 UI 逐项编辑和真实生成验收。额外媒体工具条、供应商图标、版本变体、复杂联动条件、真实素材上传和剪辑工作台仍待对照。
