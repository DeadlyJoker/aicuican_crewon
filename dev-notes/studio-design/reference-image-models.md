# 图片模型目录研究

2026-11-10，通过已安装 rhTV 插件与共享 CLI 只读读取当前账号可见图片目录。105 个定义包含生成及图片工具，其中 38 个图片生成名称分别有文生图、图生图定义，共 76 份。`reference-image-model-catalog.js` 只保存显示名称、模型代码、参数与显示规则，不保存账号、凭据、SKU、价格或请求回执。此快照不表示 CrewON 已接入对应供应商。

资产页模型菜单支持搜索与选择。未选择具体模型的旧项目保留“跟随项目模型”和原通用参数；选择具体模型后初始化其文生图参数，不携带另一模型的字段。恢复“跟随项目模型”不会删除之前通用参数。画布图片节点共享此目录，保留旧示例项；批量和节点生成均未接入真实执行。

字段标题由模型配置映射，不能把 `whResolution` 等内部名直接展示给用户。Seedream 的宽高由配置里的比例／分辨率尺寸表确定，展示计算结果；本轮不提供自定义宽高编辑。不同模型的文生图／图生图定义分别保留，但资产页目前仅准备文生图参数；不能据此声称已完成变装与图生图执行。复杂条件字段、全部模型的控件行为尚未逐项验收。

实际界面检查：搜索 Seedream、选择 5.0 Lite、刷新恢复、16:9／4K 对应 4096×2304，切换 G2.5 高品质版恢复其自适应／1k／高默认值，没有残留 Seedream 尺寸字段。7 项目录检查覆盖双定义完整性、切换隔离、未知模型不覆盖、尺寸表、引用图模式与菜单定位。

节点实测：选择 Seedream 5.0 Lite，16:9／4K 对应 4096×2304，生成本地示例候选 v2；切换 G2.5 高品质版并刷新，后续配置为新模型，v2 仍保存 Seedream 与原尺寸，当前采用仍为 v1。模型菜单按上下空间翻转，打开时层级高于节点工具栏。图生图定义选择已有自动检查。

图生图界面实测：从林晚已采用 v1 派生图片草稿，选择 Seedream 5.0 Lite，候选保存 `image-image-seedream-v5-lite`、1:1／2K 和来源 v1。移除当前草稿参考后，参数面板切回文生图；刷新重开候选仍显示图生图与来源 v1，不随草稿移除。此验证仅生成本地示例候选，未请求真实模型。
