# CrewON Studio design study

English | [中文](README.zh.md)

This directory contains the standalone Studio interaction prototype, local reference assets and isolated tool experiments. Open [index.html](index.html) to inspect the prototype. Production behavior belongs to [the short-drama bundle](../../packages/bundle/short-drama/README.md); prototype controls alone do not establish production capability.

## Research records

The complete dated validation log is retained in [validation-history.log](validation-history.log). It records observations and unresolved checks at the time of each experiment; it does not establish current runtime state. [The panorama study](reference-panorama-study.md) owns its focused observations. [Artwork sources](icon-artwork-source.md) and [reference asset sources](assets/reference-study/README.md) identify the retained materials and their usage limits.

## Isolated tool studies

The tool directories own setup and evidence for [text editing](tools/text-editor/README.md), [color selection](tools/color-picker/README.md), [panorama rendering](tools/panorama/README.md), [calibration fixtures](tools/fixtures/README.md), [HyperFrames playback](tools/hyperframes/README.md) and [the HyperFrames editor](tools/hyperframes/editor-check/README.md).
