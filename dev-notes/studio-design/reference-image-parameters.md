## 本地缺口与实现约束

当前 `canvasMediaParametersHtml` 的图片分支只有自适应、16:9、9:16、1:1以及1K／2K，没有生成质量。`canvasMediaSettings` 已保存比例和分辨率到候选，但没有图片质量快照。资产页全局参数按钮仍禁用，不能把节点级参数保存冒充批量生成已接通。

后续应先复用节点参数解析与候选快照，补图片质量字段和模型选项目录，再实现同一浮层的网格布局；图像、视频和音频各自保留参数，不把图片新增字段写入声音或覆盖旧视频参数。已保存候选必须维持原值，旧记录缺质量时展示“未记录”，不能补写为当前默认值。模型切换后需要对照真实能力约束选项，不能把本页观察到的全集硬编码成所有模型的支持范围。

验收需要在节点中选择非常规比例、4K及质量，保存两份不同配置候选，刷新后回看第一份不变；同时复核视频和声音候选没有新增图片字段。资产页批量参数在缺少真实执行链路时继续保持不可运行状态。
