# CrewON Studio 设计研究

[English](README.md) | 中文

本目录包含独立的 Studio 交互原型、本地参考素材与隔离工具实验。打开 [index.html](index.html) 可查看原型。生产行为由[短剧 bundle](../../packages/bundle/short-drama/README.zh.md)负责；原型控件本身不能证明生产能力。

## 研究记录

完整的带日期验证日志保留在 [validation-history.log](validation-history.log)。它记录各次实验当时的观察及未完成检查，不代表当前运行状态。[全景研究](reference-panorama-study.md)维护该功能的专项观察。[图标来源](icon-artwork-source.md)和[参考素材来源](assets/reference-study/README.zh.md)说明保留素材及其使用限制。

## 隔离工具研究

各工具目录分别维护[文本编辑](tools/text-editor/README.zh.md)、[颜色选择](tools/color-picker/README.zh.md)、[全景渲染](tools/panorama/README.zh.md)、[校准夹具](tools/fixtures/README.zh.md)、[HyperFrames 播放](tools/hyperframes/README.zh.md)和 [HyperFrames 编辑器](tools/hyperframes/editor-check/README.zh.md)的配置说明与证据。
