# 摄像机控制交互研究

2026-11-10 在已授权的 rhTV 研究画布打开图片节点下方摄像机控制。它是相机、镜头、焦距与光圈的风格参数选择器，不是三维相机位置编辑器。顶部预览明确说明仅展示当前分类的参考效果，不代表组合结果。

初次 DOM 只有当前项上下各两项，不能把这五项视为完整目录。实际通过键盘循环逐项遍历，记录 22 款相机、10 款镜头、10 档焦距、8 档光圈；原始可见内容与缩略图地址见 rhtv-camera-catalog.json。原站默认 Sony VENICE、Zeiss Ultra Prime、8 mm、f/2.8，开关关闭。菜单可恢复默认、保存最多 20 个配置。本次未保存原站自定义配置、未生成图片，检查后恢复默认。

Demo 用同样的五行循环选择、四个分类与单项参考预览，支持键盘上下、滚轮和拖动。配置属于当前节点草稿；开关关闭时不写入执行设置，开启后下一份候选记录独立配置，不改写原采用图像。保存配置仅在本机浏览器可用。研究图片在 assets/reference-study/camera，正式发布须替换为自有或获许可图片。

本地 Web 已实测相机及焦距键盘循环、焦距拖动从 14 mm 到 20 mm、开关、保存“人物广角参考”、刷新恢复、默认恢复和再次应用预设。示例候选 v5 留存 ARRI ALEXA 35、Zeiss Ultra Prime、20 mm、f/2.8，原采用 v1 保持。
