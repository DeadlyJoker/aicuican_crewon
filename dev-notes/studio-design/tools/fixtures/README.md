# Original panorama calibration fixture

English | [中文](README.zh.md)

`panorama-calibration.png` is an original 2048 × 1024 RGB grid. Four longitudinal color bands, 128-pixel latitude/longitude spacing and a white equator make spherical distortion and view changes visible without using a photograph. It is an engineering fixture, not generated creative content.

Regenerate it with `node dev-notes/studio-design/tools/fixtures/build-panorama-calibration.mjs` on the repository's supported Node version. The local Web collection may retain this file for repeatable manual checks; temporary canvas copies should be deleted through the normal recoverable node command after verification.
