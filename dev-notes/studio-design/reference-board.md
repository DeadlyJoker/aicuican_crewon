# 画板交互核对

原站画板入口为 `/sketchboard`，包含“2D画板”与“实时模式”；3D 导演台不是这里的第三个模式。切换时提供同步覆盖或保留各自绘画的选择。2D 底部工具包含选择、画笔、形状、线条、橡皮、油漆桶、文本、图片、颜色、粗细、稳定器、撤销重做、清空、保存和截屏；图层和快捷键在右下。实时模式为绘画与生成预览双栏，包含手动／实时生成、画面风格、描述、结果历史和下载。原站检查未新增绘画、未触发生成，结束时恢复原有实时模式。

本地 Demo 的 2D 操作使用 Fabric.js 6.9.0，不手写选中、移动和缩放算法。当前已实现矩形／椭圆／三角形／线条、自由画笔、可编辑文本、本地 PNG／JPG／WebP 图片、对象缩放与移动、图层顺序和显隐、删除、撤销重做、画面缩放、本机工程保存、PNG 与 JSON 导出。文件先限制 5 MB，再压缩到最长边 1200 像素；不是原始图像的无损编辑器。

2D 与实时模式分别保存内容；同步切换是明确操作。工程随本地项目保存，导出对象保留图片文件名。画板打开时底层主界面 inert，关闭恢复焦点；保存失败保留打开的画板，提示用户导出。实时生图尚未接入，预览明确为空，生成禁用。

当前仍缺少原站的像素橡皮、油漆桶、笔触稳定器、实时生成和生成结果回传；不宣称与原站画板能力完全相同。图层合并、专业剪辑不在此实现中。

已实际验证：矩形绘制与移动、撤销／重做、文本输入、图片导入与缩放、图层显隐与排序、独立模式切换、关闭后重新打开、页面刷新、图片和工程文件下载。下载 PNG 已打开检查，JSON 包含独立文本和图片对象及文件名。3 项历史模型检查通过。浏览器截图：`studio-drawing-board.png`。

第三方来源与完整性见 [Fabric.js 记录](third-party/fabric/README.md)。本轮仅修改 `dev-notes/studio-design`，未接入生产插件或真实生成服务。


项目隔离验证：另一份全剧示例的画板为空，返回草稿 17 后图片与文本仍存在，未互相覆盖。窗口缩小时自动适应内容并预留底部工具条空间。下载改用 Blob，已取得实际 PNG 和工程文件；不再以 data URL 触发下载。


## 工程列表与文件回导

保存工程按原站新建／覆盖标签组织，包含封面、名称、模式与大小；数据存到本机工程列表，多个项目可以载入同一命名工程。覆盖是显式选择，不新增同名条目。载入前当前未收录内容保存为独立备份。工程文件可重新导入，保留两个模式的对象，撤销历史重新开始；不能直接读取 rhTV 专有工程格式。

实际验证了新建、覆盖、封面替换、文件导出与重新载入、备份恢复及刷新。导出空文字样式的数组形式已兼容；外部图片地址、不支持对象与属性会在载入前拒绝，原内容保留。快照比较按字段排序，避免仅 JSON 键顺序不同就重复备份。7 项工程模型检查通过。
