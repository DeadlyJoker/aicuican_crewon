# CrewON Studio 节点交互

2026-11-09。产品设计 Demo 当前行为；原页面观察及截图见[rhTV 实际交互拆解](rhtv-interaction-inspection.md)。

## 交互分层

| 层级 | 当前行为 |
| --- | --- |
| 选中节点 | 工具条在节点上方，提示词框在下方；按节点位置更新，不固定在窗口上下 |
| 提示词编辑 | 修改该节点下一次制作输入；参考、模型方案和参数仍可设置；不同节点分别保留 |
| 专用工具 | 打光、角度、人物调节使用各自面板、参数与预览说明，关闭后返回原提示词 |
| 深度编辑 | 明确进入属性栏编辑原有高级字段，不作为所有操作的统一容器 |
| 候选比较 | 提交仅追加候选，保留原采用和历史；明确选择后才采用 |

面板围绕节点定位，窗口边缘才避让；节点完全移出画面时隐藏，重新进入时恢复。打开较高工具时，必要的视图调整让节点和操作区同时可见。窄屏保持工具条可横向滚动、面板正文可滚动、关闭与提交可达。菜单按触发控件定位，避免被工具条滚动区域裁切。

## 状态与执行范围

提示词草稿与三类工具草稿独立。关闭工具不提交，不改写原提示词；重置只重置当前工具；工具执行输入生成时捕获参数副本，后续编辑不改变旧候选。角色资料、引用、剧本与候选的原有保护机制继续保留。候选使用示意照片，预览仅说明光源位置或平面透视；人物面板显示参数选择，不宣称已生成真实表情。

本轮实现不是源站所有能力的复制：未加入真实媒体 API、3D 人脸或场景重建，其他工具继续使用原有工具说明或原型入口。不能把这些入口解释为实际图像处理已经可用。实际点击、截图与验证记录见[节点工具验证](demo-v2-review.md#节点工具验证)。
