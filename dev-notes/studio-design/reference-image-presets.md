## 观察结果

风格库复用首页风格选择器，包含风格广场、我的风格、我的收藏、最近使用，支持类型筛选与搜索。节点当前风格以带缩略图的独立标签显示，和角色设计分开。

预设分为滤镜、功能、自定义。滤镜可见 12 项（包含禁用的“无”），功能可见 11 项；标签和缩略图地址记录在 rhtv-image-presets.json。选择柯达后弹窗关闭，提示词旁出现“柯达 ×”。点击标签本体重新打开预设选择器，点击叉才移除，两者不是同一个操作。

自定义页是前缀与后缀两个编辑区，左侧为已保存预设列表。没有内容时保存入口没有打开命名表单；填写前缀后，“保存为预设”打开只含名称的二级弹窗。本次取消命名并清空前缀，没有确认云端保存。应用是否会拼接最终模型请求、滤镜和功能的具体生成参数尚未验证，不根据名称编造 API 定义。
