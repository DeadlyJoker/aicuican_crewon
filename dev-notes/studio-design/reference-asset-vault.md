# 用户资产库与项目引用的区别

2026-11-10实际点击原站画布左侧“资产”，以及研究画布中苏晚节点右键“加入我的资产”。原站页面中的资产库与角色模板库、剧本实体、制作参考选择器是不同入口，不能合并成一个根据当前节点自动变换含义的按钮。

## 观察结果

- 左侧“资产”打开约360px宽的浮层，包含资产库标题、新建文件夹、放大和分类入口。当前账号为空时显示“暂无资产，可上传或从画布加入”；即使画布已有图像，也不会自动列入。
- 新建文件夹为局部表单，包含文件夹名称、分类和创建按钮。没有填写名称时创建禁用。本轮只打开与关闭，没有创建文件夹。
- 分类入口包含全部、角色、场景、道具、风格、商品、其他。尚未核实不同分类的上传限制。
- “放大”打开大弹窗，左侧目录，右侧内容；顶部提供我的资产／收集箱、列表／网格、新建文件夹、管理、搜索和关闭。空目录会提示选择文件夹，不能拿当前画布所有节点填充。
- 研究画布中单个图像节点右键有“加入我的资产”。打开后显示已选择1项素材，表单要求分类与保存位置，未选文件夹时保存禁用。当前图像的分类默认为角色。只打开选择器并取消，没有保存素材或修改账号资产。

截图：`rhtv-asset-vault-expanded.png`、`rhtv-save-asset-form.png`。保存表单中的可见分类标签与技术值并不完全一致，不以DOM中的USER_CHARACTER等内部值作为产品文案。

## Demo现状与接入方向

目前 `openStudioAssetLibrary` 在选中可制作节点时会打开制作参考选择器，未选中时显示当前项目素材；这与“我的资产库”的语义不同。应保留原项目引用选择器作为提示词框里的加参考能力，单独把画布资产入口接到用户主动收藏的资产与文件夹数据。

保存资产需要复制当时采用版本的素材快照，保留来源项目、节点、候选版本和类别。之后修改原节点不能改写已存资产。重新加入画布创建独立节点，不能隐式注册为剧本角色。旧项目节点与旧引用保持原样，不自动迁入用户资产库。

首个验收链路应为新建分类文件夹、把已有节点的采用版本保存进去、切换项目后查找与复用、回到旧候选确认其未变、刷新恢复，以及取消保存不产生资产。无采用输出的节点不得存成看似已生成的素材。当前尚未实现这个独立用户资产库，本记录不能作为已交付证明。

## 本地实现进展

画布“资产”已接到独立本机资产库，制作参考选择器不变。新增分类文件夹、搜索、目录过滤、放大浏览；节点右键“加入我的资产”保存当时采用版本，不复制未采用草稿。存储不属于单个项目草稿，项目切换后仍可访问。相同来源项目／节点／版本在同文件夹去重，复用创建独立节点，并使用原画布撤销记录。新建文件夹空名称及未选保存位置时提交禁用。

实测在草稿17创建“角色参考 · 验收”，保存林晚采用v1，双击保存后目录仍只有一项；刷新后复用并撤销，再切换“末班灯 · 全剧示例”查找同一项并复用、撤销，最后返回草稿17。测试副本均已撤销，保存的验收资产保留供查看。窄屏及放大浏览截图为 `studio-asset-vault-narrow.png`、`studio-asset-vault-saved.png`。15项资产库和节点检查通过；模型覆盖来源编辑后快照独立、重复保存去重和撤销不删除资产库记录。

仍未接入收集箱、上传、资产移动／删除、完整管理模式及云端同步。当前只完成本地Demo，不表示正式DSH插件或App已经支持用户资产库。

## 首页入口统一

原站首页导航的资产库是独立页面，显示个人资产／团队资产／收集箱、搜索、类型筛选和文件夹，而画布是浮层，两者指向同一类用户资产。当前Demo首页资产库已复用上述本机数据，按文件夹进入查看，不再打开项目引用选择器。未实现的团队资产和收集箱保持禁用。

首页“加入项目”先让用户明确选择目标项目，再创建独立副本；画布内仍直接加入当前画布。本地实际选择全剧示例、确认到达该项目并新增副本，随后撤销，资产库内的保存版本不变。搜索同时匹配文件夹名称和其中的素材名称；进入文件夹清除外层搜索。刷新`#assets`的首次渲染问题已修正并实际验证。390×600页面控件与素材可见，截图 `studio-home-assets.png`、`studio-home-assets-narrow.png`。4项资产库模型检查通过，原站导航验收后已返回研究画布。

## 键盘与浮层验收

资产抽屉打开后聚焦搜索框。按 Escape 关闭抽屉并返回画布“资产”入口；存在新建文件夹弹窗时，第一次 Escape 只关闭弹窗，第二次才关闭抽屉。2026-11-10 在独立研究项目实测这两条路径通过，未提交文件夹或更改素材。保存版本隔离的 4 项模型检查通过；本轮没有重新进行切换采用版本的浏览器验收。

## 文件夹分类与收集箱复核

2026-11-10 再次通过原站首页资产库打开新建文件夹，分类为角色、场景、道具、风格、商品、其他六个平铺按钮。Demo 对应表单改为平铺选择，实测切换到场景后仅场景保持选中，名称为空时创建仍禁用；取消未写入文件夹。原站收集箱另有安装插件、本地上传、下载插件、安装说明以及 RHClipper 支持的网站区域，不能用普通资产列表代替。此次仅查看并取消原站表单，未创建远端数据。

截图复核同时发现资产抽屉的层级高于通用弹窗，导致新建表单左侧被遮挡。已将抽屉打开时的通用弹窗置于其上方，重载后重复点击分类、取消并截图确认表单完整可见。
