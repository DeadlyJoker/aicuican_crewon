# Studio 项目工作区

状态：产品边界已确认，隔离实现待完成。现有短剧插件仍沿用默认原生工作区，不能把当前状态称为项目工作区隔离。

## 用户体验

进入 Studio 切换到 Studio 专属项目导航，主页工作区、会话、搜索与滚动位置留在主页上下文。一个项目就是一个工作区；同一项目可以包含不同集数与多段创作会话，不能把一集等同于一个新项目。切换项目只显示该项目的会话、资产、分镜、画布、任务与导出历史。退出 Studio 恢复主页原来的上下文。

主区域保留原生 Agent 对话、工具审批和轨迹；右侧承载原型的项目工作台与无限画布，支持拉宽及全屏。进入某个项目应同时选择其原生会话与右侧内容，不靠生成按钮才建立关联。右侧选中对象形成显式请求，Agent 负责创作和编排，API 负责执行。

## 共享与隔离

账号、模型连接、凭据引用、插件启用、工具箱和专家目录继续共用当前 Host，不启动另一套内核。每个项目有独立的工作目录、Session 集合、创作数据、模型上下文、API 路由配置、画布布局、任务和媒体历史。授权仍沿用宿主机制；产品工作区隔离不能被描述为针对恶意工具的安全沙箱。

主页与 Studio 的会话搜索、最近项目、新建会话默认目标和工作区选择器均需按产品上下文过滤，不能只隐藏左侧文件夹。后台任务继续随原项目运行，切换产品或项目不能取消任务，也不能把输出写入当前屏幕上另一个项目。

## 原生能力与需要补的接口

原生 WorkspaceRegistry 已支持真实目录、会话归属、归档与持久化，但没有产品归属字段或产品视图过滤注册点。现有 Studio 的 openConversation 使用首个注册工作区，需要替换。复用 WorkspaceRegistry 和 SessionController 创建项目工作区，通过公开、可释放的产品工作区注册点投影主页与 Studio 的可见集合；不读取其他插件私有 store，不覆盖全局工作区列表，不修改 Agent loop。

短剧插件新增独立的项目工作区关联域，保存项目、原生工作区、当前项目会话及旧会话引用。项目工作目录根位置是经校验的插件配置，目录名使用项目身份，不使用用户标题作为路径。关联更新应支持重启后的幂等恢复；同一项目并发打开只能得到一个工作区和一段初始会话。工作区目录创建失败时保留项目，并显示可重试的明确错误。

## 已有项目

现有 short_drama_projects、short_drama_production 和 short_drama_canvas 不清空。旧会话的 cwd 与提交日志不改写；为旧项目建立新工作区时保留旧会话引用和历史入口，新会话使用新工作区，所需上下文以原生、可重建的会话输入显式提供。不能用复制日志并修改 cwd 的方式伪造原会话迁移。3090 原型的浏览器草稿和 IndexedDB 素材另行完整导入，原始数据在验收前保留。

## 验收

从主页已有会话进入 Studio，新建项目 A 和 B，各自发起创作，确认目录、会话、资产引用、画布、任务和候选均不会串项目。项目 A 执行期间切到 B 和主页，A 的执行继续并归档到 A。主页的树、全局搜索、最近项和新会话目标不混入 Studio 项目。退出后恢复主页会话、输入草稿、搜索和滚动；重启 Web 与 App 后关联、历史和导航仍一致。旧项目历史保持可读，新工作区不改写旧 Session 的 cwd。
