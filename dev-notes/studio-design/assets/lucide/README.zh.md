# 参考研究图标素材

[English](README.md) | 中文

这些 Lucide SVG 于 2026-11-10 从官方 `lucide-icons/lucide` 仓库下载，适用随附 ISC 许可证。来源目录：https://github.com/lucide-icons/lucide/tree/main/icons。它们用于独立本地 rhTV 交互研究，使用观察到的 1.7 描边宽度；不新增 CrewON 官方插件图标，也不修改生产 DSH 组件。`reference-icon-artwork.js` 仅替换对应原型别名，缺失别名继续使用共享 DSH 图标。

图片查看器控件使用同源同许可的 `triangles-centerline-dashed-horizontal`、`triangles-centerline-dashed-vertical`、`rotate-ccw`、`rotate-cw`、`zoom-in` 和 `zoom-out`。水平翻转使用垂直中线字形，垂直翻转使用水平中线字形。

`star.svg` 来源于 lucide-icons/lucide 的 icons/star.svg，沿用 ISC 许可，用于预设收藏。

`camera.svg` 来源于 lucide-icons/lucide 的 icons/camera.svg，沿用 ISC 许可，用于摄像机配置入口。
