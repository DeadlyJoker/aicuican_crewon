# Reference study icon assets

English | [中文](README.zh.md)

These Lucide SVG icons were downloaded from the official `lucide-icons/lucide` repository on 2026-11-10, under the included ISC license. Source directory: https://github.com/lucide-icons/lucide/tree/main/icons. They are used in the standalone local rhTV interaction study, with the observed 1.7 stroke width; they do not introduce official CrewON plugin artwork or change production DSH components. `reference-icon-artwork.js` overrides only the corresponding prototype aliases. Unavailable aliases retain the shared DSH icon.

The image-viewer controls use `triangles-centerline-dashed-horizontal`, `triangles-centerline-dashed-vertical`, `rotate-ccw`, `rotate-cw`, `zoom-in`, and `zoom-out` from the same source and license. Horizontal image reflection uses the vertical-centerline glyph; vertical reflection uses the horizontal-centerline glyph.

`star.svg` comes from lucide-icons/lucide icons/star.svg under ISC and marks preset favorites.

`camera.svg` comes from lucide-icons/lucide icons/camera.svg under ISC and opens camera configuration.
