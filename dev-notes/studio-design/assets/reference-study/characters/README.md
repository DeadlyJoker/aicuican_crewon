# Character-library reference assets

English | [中文](README.zh.md)

The 60 local WebP files came from 20 three-view sets observed by opening character details on 2026-11-10; source.json retains their original URLs. Images were reduced to a 1200-pixel longest edge for local interaction comparison. CrewON has no implied commercial distribution right, and these are not production plugin assets. The snapshot covers only those first 20 characters, not the complete reference catalogue. A production character library requires independently authorized assets and a separate directory.
