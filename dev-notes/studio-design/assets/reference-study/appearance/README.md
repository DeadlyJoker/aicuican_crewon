# rhTV appearance-preview study

English | [中文](README.zh.md)

The generic character and hairstyle previews came from assets actually displayed by the reference UI. They are retained for local style and interaction research, without granting CrewON commercial or redistribution rights. Production assets require independent ownership or permission; the study directory is not production plugin artwork.

source.json retains each file's origin. combinations.json records the age, skin tone, hairstyle, body-shape selections and their observed previews. Deduplication yielded 288 combinations: 3 ages × 3 skin tones × 8 hairstyles × (3 body shapes or no body-shape selection). appearance-preview-catalog.js projects those records locally without contacting the reference site.

The previews are static generic characters, not actual edits to a user's character. The study submitted no generation or payment and cancelled no existing user task. Appearance options were restored to an unselected state afterwards.
