# rhTV makeup-preset study

English | [中文](README.zh.md)

observed.json records the 83 cards actually displayed across five makeup categories, including names, order and image URLs. The corresponding visible page images were downloaded for local interface research. These sources grant CrewON no commercial or redistribution rights; production plugins require owned or licensed replacements.

makeup-catalog.js projects the catalogue locally. IDs derive from category and name, and runtime use makes no rhTV request. Reference-site inspection only changed categories and selected then cancelled presets; it submitted no generation, uploaded no image and changed no account assets.

The reference site's “Mine” category showed an upload/custom-makeup card; management after cloud upload remains unverified. Local Demo upload only creates browser thumbnails and local records. It sends no image to an external service and does not establish reference-account synchronization.
