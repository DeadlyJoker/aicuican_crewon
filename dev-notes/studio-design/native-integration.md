# Studio 原生插件接入

当前实现位于 `packages/bundle/short-drama`，沿用包名 `@deepseek-ai/dsh-short-drama-bundle`，不创建第二个 Studio 插件，不独立发布。入口、剧本工作台、资产／分镜图库和无限画布使用原生 Client 插件；旧 `DramaWorkbench` 与 `ProductionPanel` 页面已移除，原型文件仍保留供交互对照。

## 数据与执行

`short_drama_projects` 和 `short_drama_production` 的现有记录不改写、不删除。新增 `short_drama_canvas` v1 保存语义节点位置和视口，单独使用乐观并发版本；布局修改不增加剧本、资产或镜头版本。两端访问同一 GUI Host 时读写同一组存储域，不能用浏览器 localStorage 作为业务数据源。

3090 原型的浏览器草稿和 IndexedDB 素材没有清空，也没有自动转换为生产记录。后续迁移必须单独保留完整原始归档、媒体与映射，不能只搬运节点文字后声称迁移完整。独立原型中的示例采用状态不等于真实生成结果。

## 界面分工

Studio 的项目入口、创作工作台、资产／分镜图库与无限画布完整放入原生右侧栏；支持宿主的拉宽与全屏，不复制 CrewON 导航栏。节点沿用原有内容身份；连接资产与镜头会更新真实资产引用。提示词编辑浮层随选中节点定位；普通按钮、弹窗、主题和字号使用宿主控件与变量，画布几何独立设计。

创作助手打开项目绑定的原生会话，工具仍由已有项目作用域校验。剧本创作与媒体生成按钮向主对话提交普通 Agent 请求，执行过程与工具审批留在宿主对话；右侧仅编辑、预览、采用候选与配置。请求不覆盖输入框草稿，正在运行或已有待提交消息时拒绝重复发起。对话顶部的「查看 Studio」打开当前项目画布；Agent 完成本轮后刷新右侧项目记录，不另造聊天消息流或监控窗口。

## 分发准备与验收

保留 `private: true`、`dsh.bundle`、`dsh.client`、exports、files、Host／Client 构建和 bundle patch。插件进入内置可选清单，继续支持作为产品组成启用；未来独立分发仍需解决 workspace 依赖、版本约束和干净安装，当前未发布任何包。

检查分别覆盖真实 composition 下的布局并发冲突与输入拒绝、原有项目作用域工具与剧本版本、Web／桌面共享读写、重新打开后的布局与数据、窄屏与宿主主题。没有执行生成 API 时不得以预览图或界面状态代替真实生图／视频验收；没有逐项核对时不得把所有原型工具称为已迁移。
