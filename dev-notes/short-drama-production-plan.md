# CrewON 短剧全流程验收方案

CrewON 在原生工作台内管理项目和制作流程。验收以一集可播放、可追溯、重开后能继续编辑的成片为终点。

## 产品范围

原生工作台按剧本、资产、分镜和剪辑导出组织，生成操作位于资产与分镜中。剧本保存候选版本并由用户采用。资产包括角色、场景、道具和音色定义；服装变体可作为独立角色资产描述。同一资产版本可以用于多镜。分镜显示引用资产、来源版本、生成候选与采用状态。剪辑使用已采用的视频与配音，支持镜头排序、按帧裁剪、字幕、MP4 与字幕文件导出。

外部平台的分集导航、素材引用、逐镜候选预览和时间线仅用于产品对照。项目、会话、素材、任务与成片不使用外部平台的账号、项目对象或画布。媒体推理可以使用远程或自托管 API；更换执行服务不改变 CrewON 的项目结构。

## Agent 与 API

- **Agent 负责创作和编排。** 项目会话使用 DSH 原生模型、工具与轨迹。Agent 读取绑定项目的剧本和简明制作概览，保存资产与分镜定义，并提交或查询媒体任务。工作台与 Agent 共用 Host 服务。采用动作由用户在工作台完成，Agent 不自动替用户采用候选。
- **媒体 API 负责执行。** 每个项目分别选择图像、视频和配音服务、地址、模型与音色。OpenAI 兼容接口执行生图、参考图编辑和配音；DashScope 接口执行异步视频；`jobs-v1` 可接独立执行服务。请求使用已保存提示词和已解析的素材引用，返回的媒体归档到 CrewON。视频服务的提示词改写关闭。设置只保存凭据引用，由 Host 经 DSH 凭据服务解析密钥。
- **CrewON 持有项目和交付记录。** 项目、版本、素材归档、制作任务、时间线和成片记录属于 CrewON。更换能力配置影响后续提交，已提交任务仍按创建时的配置和任务标识查询。项目编辑、历史查看和本地导出可独立于生成服务运行。

项目服务检查会话归属与写入版本。原有剧本存储保持兼容，制作数据单独持久化。剧本、资产和分镜保留历史版本；分镜引用固定的剧本与资产版本，来源改变时标记待复核。生成请求固定目标版本、执行设置与素材输入，先记录请求再提交。重复确认同一个请求标识不会再次提交。受理未知时保留原请求和已知任务标识，查询失败不视为生成失败，也不自动重做。同步生图或配音响应丢失后，服务无法按任务恢复时应明确显示未知状态。

候选媒体与成片存入 Host 私有目录，通过两端共用的原生已认证连接预览和下载，支持字节范围播放；客户端不访问媒体文件路径。剪辑保存精确素材标识、顺序、起始帧、帧数与字幕。导出固定这组输入，经真实 FFmpeg 编码和 FFprobe 核对后写入历史。后续修改时间线不覆盖旧成片。

音色资产在本轮保存声音创作定义，配音使用项目 API 选定的音色；个人声音克隆、训练与逐角色绑定执行模型不在当前实现中。剪辑是镜头级排序与裁剪，不包含多轨合成、转场或音频波形编辑。

## 全流程验收

验收在同一项目中连续进行，使用已有剧本数据时不要求重建项目。用户可以手动编辑，也可以在项目会话中让 Agent 创作；关键采用动作和成片检查保留给用户。

| 阶段 | 全流程验收 |
| --- | --- |
| 剧本 | 从想法起草或导入剧本，改写一场，采用版本，重开后读取同一正文。 |
| 资产 | 保存角色、场景和道具定义，生成并采用参考图；修改资产保留旧版本。配置用于配音的执行音色。 |
| 分镜 | 从已采用剧本拆出两场三个镜头，至少两镜引用同一角色和场景版本。 |
| 生成 | 使用已配置的真实 API 生成关键帧、视频和配音。预览并采用，单镜重做保留历史。 |
| 剪辑与导出 | 用已采用的镜头、音频和字幕编辑时间线。冻结输入版本，导出可播放的 MP4 和字幕文件。 |
| 恢复 | 运行中重启 Host，使用原任务标识查询，核对没有重复提交。重开项目继续编辑时间线；更换执行配置后仍能查看旧任务、素材和成片。 |

全流程完成须由实际配置的生图、视频和配音 API 生成媒体，在 CrewON 工作台检查画面、声音、字幕和播放，再重开项目继续编辑。协议夹具、真实编码与真实生成分别记录证据，不能互相替代。

## 本轮开发验证（2026-11-09）

本地 Web 已用显式测试 HTTP 服务完成剧本、资产、分镜、候选采用、剪辑和导出操作。测试服务提供可识别的媒体夹具，CrewON 实际归档素材并通过真实 FFmpeg 导出，浏览器已播放 7 秒 MP4。这验证产品链路与编码输出，不代表外部模型生成了一集短剧。

本机当前未配置可用的生图、视频或配音 API 凭据，真实生成质量与整集制作尚未验收。取得明确的服务地址、模型和 DSH 凭据引用后，按上表重跑真实生成及重启恢复。执行协议的配置方式与失败语义见[短剧插件说明](../packages/bundle/short-drama/README.zh.md)。
