# Studio 媒体能力接入方案

## 分工与兼容性

DSH 继续拥有项目、会话、审批、任务身份和媒体归档。媒体工具只处理 Host 已归档的文件，返回结构化结果，不创建第二套项目或会话。Web 与 App 使用同一个 Host 服务。分析结果独立保存，不修改已采用剧本、分镜、媒体或旧导出。

| 能力 | 接入方式 | 启用条件 |
| --- | --- | --- |
| 视频与音轨信息 | 现有 FFprobe，经 DSH subprocess 调用 | 文件属于当前项目，输出通过校验 |
| 镜头切点 | FFmpeg 场景变化检测 | 作为建议区间返回，不自动改剪辑；闪光、运动可能误判 |
| 自动字幕 | 可选 whisper.cpp 原生程序与明确的本地模型 | 不自动下载模型；缺少配置、无音轨分别报告；转写不是对白准确性证明 |
| 专门镜头检测 | PySceneDetect 候选适配器 | FFmpeg 基线与实际素材比较后再决定是否引入 Python 运行时 |
| 多轨剪辑 | MLT 合成，FFmpeg/libass 编码及字幕 | 已接入版本化轨道；部署提供原生引擎，发布依赖仍须审核 |
| 配音 | 保留现有媒体服务接口，可接 CosyVoice 服务 | 实际 API 协议与模型授权确认后配置，不将 GPU 模型塞进客户端 |
| 工程交换 | OpenTimelineIO 候选导出器 | 时间线语义稳定后接入；它不负责预览或渲染 |

## 首批落地

原有剪辑界面增加当前片段的素材分析入口，显示实际视频与音轨信息、镜头区间和可选字幕。项目 Agent 使用相同服务，读取结果后提出剪辑或对白检查建议。检测和转写的结果都绑定媒体身份；切换候选不会覆盖旧结果。读取、重复请求和重启均保留相同结果；同一请求身份不能换素材或换分析方式。

分析以独立存储域记录开始、成功或失败。重启后的未完成任务显示中断，不伪装完成，也不自动重新处理。用户可用新请求重试；完成结果直接重读。子进程使用 DSH 管理、超时和取消；输出、时长及结果数量均受配置约束。媒体路径不从客户端输入，也不出现在返回结果中。

## 自审结论与发布条件

不整体迁入 Vue/Electron 应用，不引入其内存任务队列，不将文件存在等同于审片通过。第一批只新增分析服务与显式操作，不变更原有时间线和导出语义；旧记录无须迁移。多轨文档已独立于旧顺序时间线接入；MLT 负责画面与声音，字幕经人工确认后进入时间线。运行时版本及发布限制见[多轨运行时](studio-multitrack-runtime.md)。FFmpeg 是已有依赖；whisper.cpp 为可选部署组件，其版本、模型和许可需随部署记录。

验收需覆盖真实带音轨视频、无音轨视频、切点、转写不可用、错误媒体身份、重复请求、重启、两个客户端读取、失败保留旧项目和取消清理。模型转写必须另外用实际语音验证，不以模拟响应替代。现有逐帧裁切与导出测试继续通过后，方可交付本批。
