# Face control visual study

English | [中文](README.zh.md)

These 55 PNG images are observed public interface preview assets from the rhTV face-control dialog, downloaded through the visible browser elements on 2026-11-10. They depict generic preview heads, not the user's production characters. This standalone local design study does not grant redistribution or commercial packaging rights. Keep production artwork independently licensed.

Source root: `https://rh-canvas-files.xiaoyaoyou.com/canvasfile/pose-control/`. `neutral.png` corresponds to `emotion-face-transparent.png`; the 36 emotion images retain names from `emotions/source-cutouts/`; nine gaze images retain names from `gaze-eyes/`; nine mouth images retain names from `mouth-faces/`. Images are retained without modification. No rhTV runtime code or generation API is included.
