# rhTV 妆容预设研究

[English](README.md) | 中文

observed.json 记录原站 5 个妆容分类下实际展示的 83 张卡片名称、顺序和图片地址；本地文件由对应页面图片元素下载，仅用于本机界面研究。来源素材不表示 CrewON 获得商用或再分发授权，正式插件必须替换为自有或已授权素材。

makeup-catalog.js 为本地目录投影，ID 由分类与名称生成，运行时不访问 rhTV。原站检查只切换分类、选用再取消，没有提交生成，没有上传图片或修改账号素材。

“我的”在原站表现为“上传图片／自定义妆容”卡片；云端上传后的后续管理尚未验证。本地 Demo 的上传仅在浏览器生成缩略图并保留本地记录，不向外部服务发送图片，不表示已复刻原站账号同步。
