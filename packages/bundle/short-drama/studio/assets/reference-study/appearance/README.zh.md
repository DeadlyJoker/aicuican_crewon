# rhTV 形象设定预览研究

[English](README.md) | 中文

本目录的通用人物和发型预览取自原站实际展示的 UI 素材，仅供本机样式及交互研究，不表示 CrewON 获得商用或再分发授权。正式产品须替换为自有或已授权素材，不把研究目录装入正式插件。

source.json 保留逐文件来源；combinations.json 记录通过原站控件实际选择的年龄、肤色、发型、体态与预览文件对应关系。去重后为 288 种组合：3 年龄 × 3 肤色 × 8 发型 ×（3 体态或未选体态）。appearance-preview-catalog.js 是该对应关系的本地投影，运行时不请求原站。

预览是原站通用人物的静态展示，不是对用户角色进行真实编辑。没有提交生成、支付或取消用户已有任务；检查结束后原站形象选项恢复未选择。
