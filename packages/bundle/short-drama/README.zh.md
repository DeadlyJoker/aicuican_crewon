# @deepseek-ai/dsh-short-drama-bundle

[English](README.md) | 中文

Studio 全屏时隐藏底层导航和会话，保留其挂载状态；退出全屏后恢复显示，不改变壁纸或玻璃设置。

## 概述

这个可选配置包为原生工作台提供 **短剧**，包含剧本版本、可复用资产、分镜、媒体候选、可编辑时间线和成片导出。CrewON 持有项目数据与归档素材。Agent 在项目会话内创作，可替换的 API 负责执行。

创作卡片保留 Demo 的图片题材与风格库、四种剧本模式、画幅和集数设置。题材支持主题材与可选融合题材；风格支持分类、搜索、收藏、最近使用，以及带参考图的自定义描述。模型路由与选择继续由原生输入区负责。

## 使用本包

Studio 复用原生侧栏工作区浏览器和主 Agent 对话。每个项目拥有独立的原生工作区；关联的旧会话保留原标识和目录。进入 Studio 后，已有浏览器只显示其项目；退出时恢复主页选择、输入框草稿和搜索。原生右侧栏承载打包后的 Demo 界面与画布，可编辑文档由 Host 保存并检查版本。创作执行交给项目 Agent，执行与审批使用原生机制。Web 与桌面连接同一 GUI Host 时共享项目记录和 Studio 文档。独立的 3090 原型及其浏览器素材保持原状，不会自动导入。

在 Studio 中，全局**新建项目**入口在原生对话内打开 Demo 创建界面，不为当前项目添加会话。项目行的加号在该项目工作区新建会话，使用配置的 `directorPreset`。会话创建完成前重复点击共用一个请求。点击普通对话导航才退出 Studio。每个项目记住最后打开的会话，包括关联历史；重启恢复时优先保留原生会话的当前选择。切换项目或退出时保留各会话原有的右侧栏布局；创建入口只关闭其自身遗留的 Studio 画布页签。草稿保存失败会留在当前页面，已被后续操作取代或已释放的导航不能重新打开旧目标。`openConversation` 继续返回项目主 Session；`createConversation` 新增 Session，不替换主会话标识或已有记录。

新建项目在原生空白对话中使用完整的 Demo 创作界面。创作、改编、制作和转绘保留独立输入；改编支持改写、续写和目标语言设置。TXT、MD、DOC、DOCX 原稿在分配项目之前由 Host 解析并归档；MP4、MOV 导入必须包含视频流，且时长不超过五分钟。确认的输入、所选设置和原始文件复制到分配的项目，并交给其原生 Agent。受理失败保留草稿，重试复用同一项目。入口设置与原件使用共享且检查版本的 Host 存储；付费生成仍需原生审批及已配置的媒体服务。项目库与画布不提供第二套创作对话。

剧本工作台通过原生项目服务编辑、保存和采用正文；修改后的正文先追加候选再采用，保留此前版本。采用前继续阻止分镜规划。用户气泡只概括创作设置与画布操作，轨迹保留完整原始输入。画布任务进入原生项目会话队列，已有任务运行时也可继续排队。画布的设置入口在当前页打开共用的原生生成服务表单，支持标准图片／语音 API 与 DashScope 视频 API，或统一任务 API；未配置服务时不会生成媒体。新项目不会带入原型的示例角色或镜头。内嵌画布使用 Demo 原有的分组排版。旧接入层的布局只修复一次，不改变创作内容；后续拖动和提示词草稿继续保留。适应内容操作按侧栏实际视口测量卡片和分组标题。原生候选的自动更新按来源版本合并，用户提示词草稿继续保留冲突保护。Web／桌面的独立文档修改基于 Host 版本合并；同一内容的冲突修改保留在原页面，显示未保存状态，不替换另一端的修改。

包继续保持 private，作为内置可选 bundle 交付，保留 exports、文件清单、Client 入口与 patch，供后续分发流程使用；当前不独立发布。


完成源码构建后，运行 `pnpm dsh web --patch packages/bundle/short-drama/cordis.patch.yml`。从侧边栏打开 **短剧**。创建项目，保存梗概和剧本候选，再采用剧本，开始规划分镜。

在 **资产** 中添加角色、场景、道具或音色定义。在 **分镜** 中规划镜头并引用可复用资产。先生成并采用资产参考图，再生成镜头图片；采用镜头图片后才能请求视频。配音使用镜头对白，候选结果可预览并明确采用。引用的剧本或资产改变后，相关镜头会标记为待复核。

每个项目分别配置执行服务。OpenAI 兼容地址包含 API 前缀，例如 `/v1/`，用于生图、图片编辑或配音。DashScope 视频适配器使用服务根地址和异步任务 API。填写明确的模型，配音另需填写音色。凭据引用指向 DSH 凭据服务保存的密钥，项目设置不保存密钥值。`jobs-v1` 适配器用于实现下述协议的独立执行服务。

服务弹窗在窗口可用高度内滚动，保存操作始终保持可见。协议名称与资产版本标签跟随客户端语言。

共用服务配置在 Host 保存一份，Studio 创建入口将配置复制到新项目；已有项目维持原设置，用户可载入共用配置再保存到本项目。每次任务保留实际使用的服务。Zealman 工作流适配器统一使用面板地址，分别选择生成与参考图编辑流程，按确认顺序上传参考素材，完成后立即归档产物。远端历史缺失表示结果未知，不允许自动重投。声音克隆流程需要明确的参考音频，不能当作通用文字配音接口；U22 可直接生成带对白的视频。

生成时在对应媒体占位区显示加载动画，不显示等待文字。已提交任务的变化在 Agent 运行期间同步到 Web 和桌面工作台。减少动态效果设置会关闭旋转；任务中断或失败时显示可处理的状态，不持续空转。原生节点在采用前展示已归档候选，点开可查看真实图片、视频或声音；采用操作由 Host 校验版本后提交。旧资产或分镜版本的候选仍可查看，但不能替换当前版本。制作历史展示已归档生成任务和可播放成片。时间线按数组顺序播放，每个起始帧独立表示该片段的源视频裁切位置。项目 Agent 可通过 `short_drama_save_timeline` 保存已采用片段的顺序，再通过 `short_drama_export_episode` 渲染；重复使用同一导出标识会返回原交付。

画布的「资产」入口打开当前项目的资产卡片。角色、场景、道具列表与画布对应分组使用相同的实时成员，尚未生成的设定也会显示。新建、删除或调整资产类型会同步两处；旧节点位置和非资产分组继续保留。资产新建、修改与删除使用原生制作服务并检查版本，生成交给项目 Agent；模型设置和分镜关联显示真实记录。项目资产图片导入和逐角色音色选择尚未接入原生候选操作，原型控件不会假报采用成功。

Studio 通过原生项目技能完成剧本诊断、资产设定、导演分镜、H3 编译和媒体审阅。诊断引用已采用剧本；设定区分原文事实、合理推导和创作设计。保存资产与分镜会更新画布节点及来源连线。制作检查面板展示这些记录、校验实际模型输入，并将创作操作交给项目 Agent。技能规则参考用户维护的 AI 短剧制作工作室；未打包第三方署名模板或外站风格快照。

结构化分镜可选择首帧、完整参考或文本模式。Host 在提交前校验时长、连续时间段、原文对白、参考用途和已采用资产版本。完整参考输入按声明用途保留图像特征，不将原来的生图指令带入剧情。参考模式不额外要求首帧；旧分镜保留已有首帧行为。计划或参考集变化后，旧结果不能作为当前输入的产物采用。审片记录按任务保存观察依据；资产和分镜审片退回会阻止采用，未检查项保持待检。资产图片编辑可将项目中已归档的图片作为参考，使用已配置的参考图模型执行。返修保留已有候选，并在新审片记录中关联原任务。旧项目缺少的创作记录按空列表读取，不重写剧本、媒体或成片。

在 **剪辑与导出** 中添加已采用的镜头，调整顺序、源素材起始帧、长度和字幕，再保存时间线。导出得到带音频的 MP4；有字幕时另有 SRT 文件。导出历史保留当次的精确输入镜头。重新打开项目可恢复已保存的时间线和归档候选。

打开项目会话，由 Agent 辅助创作与编排，再返回工作台审阅草稿。并发编辑会拒绝过期版本，应重新载入后再保存。状态未知的生成请求使用原任务标识查询，不自动重新提交。同步生图或配音 API 在受理后丢失响应时，无法自动恢复该响应。

项目导演将故事背景、人物关系、冲突、大纲及明确标出的建议设定保存为独立版本，不改动已有项目记录。它通过原生上下文记录创作方向，并按当前已采用成果推导下一步，旧项目无需补建创作方向也能接续。

最新完成的对话回复下提供紧凑卡片，供用户确认方向、采用剧本或媒体；提交前核对卡片展示的版本。继续制作仍通过普通项目对话调用现有技能、制作工具和画布归档。剧本中的阻断问题先返回修订，再进入生成。服务故障直接提供现有生成设置弹窗，保留失败尝试并由用户明确重试。生成完成不代表艺术质量已验收。

新建 Studio 会话通过可配置的 `directorPreset` 选择原生 `studio-director` 预设；已有会话保留原预设与历史。导演具备影视创作身份，复用原生提问、技能、媒体读取和检查工具。每次请求都会记录当前阶段所需的专业指导，包括生图提示词、结构化分镜和 U22 编译；其他技能仍可按需加载。这不会创建独立模型服务或绕过媒体审批。

创作选项从项目共享文档恢复，兼容旧版 `referenceOptions` 记录。导演将用户已选的题材、风格、画幅和集数作为既定选择。新故事设定必须分别包含故事定位、一句话故事、完整因果梗概、人物小传，以及与所选集数一致的连续分集大纲。旧设定仍可读取，工作台展示已有背景、人物和大纲，并提供补齐入口，不再用剧本标题填充正文。

全局新建会话及添加工作区会先保存 Studio 草稿、返回主页，再执行原生操作。Studio 项目只在 Studio 入口中新建，返回 Studio 时保留原先选中的项目。

## 理解实现

<details>
<summary>实现内部细节 — 点击展开</summary>

配置补丁挂载 Host 存储、项目会话专属工具和原生客户端。已有项目与剧本记录保留在原存储域，制作记录使用独立存储域。剧本、资产和分镜定义保留版本，媒体尝试保留当时的执行地址与输入，导出冻结时间线决策。表单和工具都由 Host 执行版本检查与项目归属检查。

媒体请求先持久化，再提交。OpenAI 兼容适配器使用 `images/generations`、携带已解析图片引用的 multipart `images/edits`，以及返回二进制音频的 `audio/speech`。DashScope 使用 `api/v1/services/aigc/video-generation/video-synthesis` 和后续的 `api/v1/tasks/:taskId`；视频使用已采用首帧，并关闭提示词改写。完成的素材复制到配置指定的私有媒体目录，不依赖服务方临时 URL。

可选的 `jobs-v1` 执行服务接收 `POST v1/jobs`，请求为 `{requestId,kind,input}`，返回已受理任务或拒绝结果。`GET v1/jobs/:taskId` 或 `GET v1/jobs/by-request/:requestId` 返回任务状态；成功结果指定由 `GET v1/artifacts/:artifactId` 提供的素材。适配器核对回执标识，限制响应大小并禁用跳转。受理回执丢失时仍保留未知状态；配置了凭据或地址可达，都不代表生成成功。

归档文件通过原生已认证连接提供 `GET`、`HEAD` 和字节范围请求，供播放与跳转。客户端只拿到媒体标识和预览地址，不接收文件系统路径。配置指定的 FFmpeg/FFprobe 根据冻结时间线编码，并核对帧数后才将成片加入导出历史。[配置补丁](cordis.patch.yml)定义编码器、输出规格与 I/O 限制。

</details>

## 模型体验

### 项目创作与执行

#### 模型看到的内容

`short_drama_read_script` 等短剧工具仅向项目绑定会话开放。短剧工具只向项目绑定的 Session 开放。Agent 可读取剧本与简明制作概览，保存剧本、资产和分镜候选，提交已配置的执行请求并查询已有任务。结果包含版本、目录标识和任务状态。采用动作保留在工作台；生成只接收已保存的创作输入，不另起故事或计划。

#### Token 影响

准入工具的定义与请求的项目上下文会进入模型请求。制作概览不包含媒体字节、服务方 URL 或凭据设置；二进制媒体保留在执行与归档路径中。

#### KV Cache 影响

工具可用性由项目 Session 关联决定。创作修改与执行查询形成普通工具调用和结果日志。媒体轮询与编码本身不增加模型请求。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

- 音色资产保存创作定义，不训练或克隆个人声音。配音使用项目 API 设置中选定的音色。
- 多轨导出需要配置 `melt` 程序以及带 libass 的 FFmpeg。这些原生组件由部署环境提供；目前不支持转场和波形编辑。
- 不同 API 的模型可用性、地域权限和允许时长不同。任务查询与结果地址可能过期；已归档结果仍可用，但丢失的同步响应无法自动重建。

<a id="dev-note"></a>
### 开发备注

<details>
<summary>维护者工作信息 — 点击展开</summary>

协议夹具验证执行与恢复，真实编码结果另行验证。制作方案独立记录真实服务验收；夹具素材可以播放，不代表 AI 生图、视频或配音的质量已经验收。

</details>

内嵌剪辑台在 Web 与桌面共享经过认证的项目素材和已保存剪辑。新多轨剪辑将画面、声音和字幕轨保存为独立的版本化文档，不改变旧顺序时间线的含义。轨道位置使用项目帧，源素材裁切使用独立偏移。视频默认保留原声，可调整音量、静音或分离到独立声音轨。识别字幕先作为候选，用户修改并确认后才加入时间线；确认操作按当前片段裁切映射时间，并通过持久化标识避免跨端重复加入。保存校验制作版本，导出按交付标识冻结完整剪辑，由 MLT 合成画面与声音，再经 FFmpeg/libass 编码并烧录可见字幕，同时提供独立 SRT 文件。旧导出继续使用原顺序编码器。保存失败保留草稿；渲染失败不发布半成品，也不覆盖旧导出。

预览跨片段复用媒体元素，预加载下一片段，并在下一画面完成解码前保留上一帧。字幕变化不重新加载视频；时间线上主动留出的空隙仍保持空白。

旧节点剪辑和保留草稿升级时保留片段标识、源快照、选中项与撤销历史。已有图片草稿继续提供静态预览，不将它们当成可导出的视频。

节点管理与资源列表共用预览渲染：已采用图片和视频读取归档素材，剧本显示已有正文，尚未生成、生成失败与预览不可用分别标识。预览不触发生图，也不改变采用状态。

临时创作入口不展示为左侧工作区；左侧只列出实际项目工作区及其会话。

新建项目界面跟随原生主面板选择：切换其他导航页时隐藏，保留草稿和已挂载文档；背景不透明，并限制在对话内容区域。

内嵌 Studio 继承宿主解析后的主题变量，并监听主题变化，不替换项目文档或画布视角。首页、画布、剧本工作台页签、文档操作条和上下文面板共享宿主背景与文字颜色；独立预览保留自己的主题开关。弹窗、菜单、图片控制与剪辑控件使用共享语义色，并保留独立预览的回退值；视频画面、字幕渲染与素材遮罩保留内容自身的颜色。 项目顶栏使用紧凑视图页签，通过下划线与按下状态标明当前视图。 节点管理、画布工具与媒体说明区采用紧凑桌面尺寸，悬停、选中和键盘焦点使用宿主语义色；触屏控件保留较大的点击范围。 跟随节点的提示词框采用限高内部滚动，工具栏紧凑横向滚动；展开提示词仍受视口高度限制。 节点工具栏保留直接操作，在窄画布中自然换行。提示词框尝试上下及左右避让，空间有限时进一步限高。 画布分为安静底面、淡色分组、内容卡片与浮动控件四层。未选中节点不显示明显轮廓，选中使用单层中性描边，键盘焦点保留宿主强调色；媒体内容颜色不变。

节点目录明确区分剧本、原生资产分类和分镜，兼容旧数据中的混合分类；无图内容与媒体卡片保持相同尺寸，使用居中的状态提示。首次原生画布按剧本、资产和分镜分栏，新节点持续自动排版，用户手动移动后停止自动重排。已有布局仅通过可撤销的整理操作调整。

Studio 新建项目入口隐藏底层会话标题，而不是用背景遮盖。紧凑的创建卡片使用统一编辑区域、对齐的参数控件及宿主主题文字和面板颜色；壁纸仍由独立的宿主层负责。
